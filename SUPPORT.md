# Support

8x8 OS is an emerging, evidence-gated project. Please use the correct channel so
your request reaches the right place and stays public-safe.

## Community support (public)

For usage questions, setup help, and general discussion about the **public**
projects:

- Open a **Documentation improvement** or **Bug report** issue on the relevant
  public repository (for example
  [`8x8-user-edition`](https://github.com/8x8org/8x8-user-edition)).
- Search existing issues first — your question may already be answered.

Community support is best-effort and provided by maintainers and contributors.
There is no guaranteed response time.

## Security reports (private)

**Do not** open a public issue for a suspected vulnerability. Follow
[`SECURITY.md`](SECURITY.md) and use GitHub's private vulnerability reporting for
the affected repository. Never post credential values or exploit details
publicly.

## Commercial or customer support

There is **no** live commercial product, paid subscription, or customer support
desk yet. The advertised `USD 8.88/month` subscription and `88 daily service
minutes` are **product targets, not live entitlements**. When a commercial
offering exists, its support route will be documented here.

## Sponsor questions

Questions about sponsorship, tiers, or recognition can be raised as a public
issue labeled `documentation` on this `.github` repository, or via the sponsor
profile at <https://github.com/sponsors/8x8org>. Sponsorship does **not** include
private support entitlements — see [`GOVERNANCE.md`](GOVERNANCE.md).

## Private owner-system matters

This organization's public repositories are **isolated public clients**. They
contain no owner credentials, private control plane, private agents, or private
memory. Requests for access to private owner systems are **out of scope** and
will not be actioned through public channels.
