## Public/private boundary

This organization does **not** publish or provide access to owner credentials, private wallets, private repositories, private messages, private memory, private agents, raw logs, internal provider routing, privileged devices, or the private 8x8 control plane.

The User Edition is the **public demo**: an isolated static cockpit plus public-safe documentation. It is not a downloadable copy of the owner system, has no connection to it, and does not receive reusable root or remote-shell authority. Nothing published here is evidence that a private runtime or production service exists or performs as depicted.

## Evidence model

Every public capability claim carries one of nine evidence states:

`CLAIMED → DESIGNED → IMPLEMENTED → TESTED → RECEIPT_VERIFIED → RUNNING → DEPLOYED → PUBLICLY_RELEASED → ADOPTED`

README text alone establishes a claim, not production truth. Per-capability states for the User Edition live in its [implementation status](https://github.com/8x8org/8x8-user-edition/blob/main/IMPLEMENTATION_STATUS.md).
