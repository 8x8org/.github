# 8x8 OS

**Bounded-autonomy human–AI systems, public protocols, and user-owned workspaces.**

8x8 OS coordinates specialized agents, evidence-backed workflows, shared context,
developer tools, and public research through **explicit permissions** and
**verifiable receipts**. Everything in this organization is a public, isolated
client of public services — never a copy of a private owner system.

## What 8x8 builds

- **[8x8-user-edition](https://github.com/8x8org/8x8-user-edition)** — the
  minimal public client: a static cockpit today, and a future signed installer,
  permission center, and isolated user workspace.
- **[8x8-protocol](https://github.com/8x8org/8x8-protocol)** — public schemas,
  receipt verification, capability contracts, examples, and SDK material.
- Additional public engineering and documentation surfaces are published only
  **after** their security and sanitization gates pass.

## Human-controlled AI principles

- **Bounded autonomy** — agents act only within explicit, revocable permissions.
- **Receipts over claims** — actions produce verifiable, auditable evidence.
- **Public/private boundary** — public clients never receive owner credentials,
  private repositories, private memory, wallets, or reusable privileged access.
- **Independent consent** — installation ≠ node enrollment ≠ compute ≠ storage ≠
  telemetry ≠ remote support ≠ rewards. Each is separately granted and revocable.
- **Truth labeling** — capabilities are staged, not overstated (see below).

## Public projects

This organization hosts only public-safe products and standards. Private owner
systems — credentials, wallets, private repos, private messages, private memory,
private agents, raw logs, internal routing, and the private control plane — are
**not** published here and are not reachable from public clients.

## Security reporting

Found a vulnerability? **Do not open a public issue.** Use GitHub private
vulnerability reporting on the affected repository and follow
[SECURITY.md](https://github.com/8x8org/.github/blob/main/SECURITY.md). Never post
credential values, wallet material, private-system topology, or exploit details
publicly.

## Current project maturity and limitations

8x8 OS is **early and evidence-gated**. Public status is labeled as one of:

`CLAIMED → DESIGNED → IMPLEMENTED → TESTED → RECEIPT_VERIFIED → RUNNING → DEPLOYED → PUBLICLY_RELEASED → ADOPTED`

- The public client is a **beta cockpit** — no backend, accounts, wallet, or
  live subscription yet.
- Product targets (e.g. **USD 8.88/month**, **88 daily service minutes**) are
  **targets, not live entitlements**. Billing is **not active**.
- No guaranteed profit, APY, token value, zero fees, or zero latency is promised.
- README text establishes a *claim*, not production truth.
