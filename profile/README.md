# 8x8 OS

**Bounded-autonomy human–AI systems, public protocols, and user-owned workspaces.**

8x8 OS coordinates specialized agents, evidence-backed workflows, shared context, developer tools, creative production, and public Web3 research through explicit permissions and verifiable receipts.

## Public organization scope

This organization hosts only public-safe products and standards:

- **8x8-user-edition**: the future minimal signed client, permission center, installer, and isolated user workspace;
- **8x8-protocol**: public schemas, receipt verification, capability contracts, examples, and SDK material;
- **8x8**: public engineering substrate after its security and transfer gates pass;
- **8x8-OS-Ecosystem**: public product and Web3 companion after its security gates pass;
- **8x8-os-a-z**: public narrative, documentation, and demo surface after topology sanitization.

## Public/private boundary

This organization does **not** publish or provide access to owner credentials, private wallets, private repositories, private messages, private memory, private agents, raw logs, internal provider routing, privileged devices, or the private 8x8 control plane.

A public client is an isolated client of public services. It is not a downloadable copy of the owner system and it does not receive reusable root or remote-shell authority.
